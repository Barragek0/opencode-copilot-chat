## Overview

Full support for the Muse Spark 1.2 family: `muse-spark-1.2-contributor` (OpenCode Go) and `muse-spark-1.2-contributor-free` (OpenCode Zen).

## Gateway constraints

Muse models are routed through the **Responses API** with two OpenCode gateway constraints handled transparently:

- `truncation: "disabled"` on every request
- Tool names truncated to **64 characters** (mapped back to originals on the round-trip, see `src/transports/extractors.ts`)

## Thinking

New `MuseThinking` strategy (`src/thinking/muse.ts`): configurable thinking effort `off / low / medium / high / xhigh` via `reasoning: { effort }`, with a Muse Spark entry in the thinking effort picker and the `opencodego.thinking.muse` setting.

## Registry & metadata

- `MODEL_REGISTRY` row routes the `muse` family → Responses API endpoint kind.
- Bundled fallback metadata: 1M context / 131K output limits when the live models.dev fetch is unavailable.
